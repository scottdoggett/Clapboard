# Clapboard

**Enrich your streaming experience with ratings, awards, and AI-powered review insights.**

Clapboard is a Chrome Extension that injects contextual movie and show information directly into streaming platforms like Netflix, Disney+, Crave, and Prime Video. Instead of switching tabs to check ratings or read reviews, Clapboard surfaces everything you need — right where you're already browsing.

---

## The Problem

Streaming platforms want you to watch *their* content — not necessarily the *best* content. Ratings are hidden or absent, reviews are buried, and there's no easy way to compare quality across sources. You end up tab-switching between IMDb, Rotten Tomatoes, and Letterboxd just to decide if something is worth your time.

## The Solution

Clapboard overlays a lightweight card on supported streaming sites that shows:

- **Aggregated ratings** from IMDb, Rotten Tomatoes, Metacritic, and Letterboxd
- **Awards & nominations** — Oscars, Golden Globes, BAFTAs, and more
- **AI-powered category scores** *(coming soon)* — Cinematography, Plot, Writing, Characters, and Soundtrack scores generated by analyzing real written reviews from across the web

## Getting Started

### Prerequisites

- **Node.js** >= 18
- **npm** >= 9
- A [Convex](https://www.convex.dev/) account (free tier works)
- Chrome or any Chromium-based browser

### Installation

```bash
# Clone the repo
git clone https://github.com/your-username/clapboard.git
cd clapboard

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Edit .env with your Convex deployment URL and any API keys

# Initialize Convex
npx convex dev

# Build the extension
npm run build
```

### Load into Chrome

1. Open `chrome://extensions/`
2. Enable **Developer mode** (top-right toggle)
3. Click **Load unpacked**
4. Select the `dist/` folder from the project root
5. Navigate to a supported streaming site — you should see the Clapboard overlay

### Development

```bash
# Start the dev server with hot reload
npm run dev

# Convex backend (in a separate terminal)
npx convex dev
```

After making changes, go to `chrome://extensions/` and click the refresh icon on the Clapboard card to reload.

## Roadmap

### Phase 1 — Ratings Overlay *(current)*
- Detect the active title on supported streaming sites
- Fetch and display ratings from IMDb, Rotten Tomatoes, Metacritic, and Letterboxd
- Normalize scores to a common scale for easy comparison
- Cache results via Convex to minimize API calls

### Phase 2 — Awards & Recognition
- Surface Oscar, Golden Globe, BAFTA, and other major award data
- Show wins vs. nominations at a glance
- Highlight award-winning content as users browse

### Phase 3 — AI-Powered Review Scoring
- Scrape written reviews from critic and audience sources
- Use AI to analyze reviews and generate category scores:
  - 🎥 **Cinematography**
  - 📖 **Plot**
  - ✍️ **Writing**
  - 🎭 **Characters**
  - 🎵 **Soundtrack**
  - ⭐ **Overall**
- Store processed scores in Convex for fast retrieval
- Display a visual score breakdown in the overlay

### Phase 4 — Personalization & Social
- User accounts and authentication
- Personal watchlists and "seen it" tracking
- Share scores and recommendations with friends
