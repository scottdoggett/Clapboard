# Extension Icons

This directory contains the extension icons used in the Chrome toolbar, extension management page, and Chrome Web Store.

## Required Sizes

| File | Size | Usage |
|------|------|-------|
| `icon-16.png` | 16×16 px | Favicon, toolbar (small) |
| `icon-48.png` | 48×48 px | Extension management page |
| `icon-128.png` | 128×128 px | Chrome Web Store, installation dialog |

## Design Guidelines

- Use a simple, recognizable design that works at small sizes
- Ensure good contrast on both light and dark backgrounds
- The icon should relate to the "Clapboard" branding (film/movie theme)
- Consider using a clapperboard or film-related symbol

## Creating Icons

1. Design at 128×128 px (or larger for retina)
2. Export at all three sizes
3. Ensure PNG format with transparency
4. Test visibility on Chrome's toolbar (both light and dark themes)

## Tools

- Figma, Sketch, or Adobe Illustrator for design
- [Real Favicon Generator](https://realfavicongenerator.net/) for automated generation
- [Favicon.io](https://favicon.io/) for simple icon creation
